# 使い方

[README](../README.md) · [動作と制限](behavior.md)

## バックアップ

1. 配布ZIPを展開し、`BackupDesk.exe` を起動します。
2. 「バックアップ」を選び、「フォルダーを追加」でコピー元を登録します。複数フォルダーをまとめて選べます。
3. 各行の「保存先フォルダー名」と、共通の保存先を指定します。
4. 必要に応じて「同時実行数」を選びます。初期値は2です。
5. 「差分を確認」で対象を確認し、「バックアップを実行」を押します。

次回は保存済みの設定を選んで実行します。「バックアップを実行」から直接、その時点の差分を再確認してコピーすることもできます。差分一覧・件数・コピー容量は全コピー元の合計です。

### 複数フォルダーの保存場所

コピー元フォルダーの**中身**を、共通の保存先配下に分けて保存します。共通の保存先が `E:\Backups` の場合は次の配置になります。

| コピー元 | 保存先フォルダー名 | 実際の保存場所 |
| --- | --- | --- |
| `C:\Work\Documents` | `Documents` | `E:\Backups\Documents` |
| `D:\Team\Documents` | `TeamDocuments` | `E:\Backups\TeamDocuments` |

たとえば `C:\Work\Documents\note.txt` は `E:\Backups\Documents\note.txt` に保存されます。コピー元に同名のファイルがあっても、保存先は別々です。

「保存先フォルダー名」にはコピー元の末尾名が初期入力され、行ごとに編集できます。コピー元が2つ以上ある場合は全行に必要です。大文字・小文字だけが異なる名前も含め重複できず、指定できるのは1つのフォルダー名です。パスの区切り文字や `..` などは使えません。

一覧から行を削除しても、元ファイルや既存のバックアップは削除しません。

### 旧バージョンの設定

コピー元1つの旧設定はそのまま引き継ぎます。「保存先フォルダー名」が空欄なら、以前と同じく保存先直下へ中身をコピーします。コピー元1つでは、この指定を引き続き利用できます。

コピー元を追加する場合は、空欄の行にも名前を付けてください。以後は保存先配下のそのフォルダーへ保存します。保存先直下にある以前のバックアップは自動で移動・削除しません。

### 同時実行数

バックアップ画面で1〜8を選べ、設定ごとに保存します。1なら順次実行、2以上なら指定数を上限にコピー元フォルダーを並行処理します。コピー元が指定数より少ない場合は、そのフォルダー数までです。

並列化する単位はコピー元フォルダーです。1フォルダー内のファイルは順番にコピーし、差分確認も順番に行う場合があります。復元は指定した複数組を行順に処理します。同じドライブへの読み書きでは、並列数を増やすと遅くなる場合もあるため、速度を見て調整してください。

「中止」は実行中の処理が停止するまで待って終了します。完了済みのファイルは残り、一部のコピー元で失敗した場合も他の処理結果とエラーを確認できます。

## 復元

復元元フォルダーの**中身**を、同じ階層構造で復元先へ戻します。たとえば `E:\Backups\Work\note.txt` を `C:\Work\note.txt` に戻すには、復元元を `E:\Backups\Work`、復元先を `C:\Work` にします。

1. 対象ファイルを使うアプリやエディターを閉じ、「復元」を選びます。
2. 「組を追加」で行を追加し、各行の「復元元フォルダー」「復元先フォルダー」を入力するか「参照…」で指定します。必要な組数だけ追加できます。
3. 「差分を確認」で全組の追加・上書き対象と合計件数を確認します。差分一覧の `[1]`、`[2]` は対応一覧の行順です。この操作では復元先を書き換えません。
4. 「復元を実行」を押し、確認画面で全組の復元元・復元先・追加件数・上書き件数を確認して実行します。処理は行順です。

復元は差分確認が必須です。確認後にパス・設定・モードを変更した場合は確認し直してください。「要確認」が1件でもある場合は実行できないため、原因を解消してから再確認します。実行が終わるまで復元元・復元先を編集しないでください。

「バックアップ設定から追加」で、現在の設定の保存先を復元元、コピー元を復元先とする組を追加できます。既存の組は残し、同じ組は重複追加しません。取り込んだ後でもパスを変更できます。

対応一覧には5組を同時に表示できます。6組目以降は一覧内を縦にスクロールして操作します。

| 復元元フォルダー | 復元先フォルダー |
| --- | --- |
| `E:\Backups\Documents` | `C:\Work\Documents` |
| `E:\Backups\TeamDocuments` | `D:\Team\Documents` |

「一覧から削除」は選択した組の登録だけを削除します。旧バージョンで保存した復元元・復元先は1組として引き継ぎます。すべての組は設定ごとに自動保存します。「復元先を開く」は選択行の復元先を開きます。

復元元同士・復元先同士に、同じ場所や互いの配下は指定できません。ある行の復元先が別の行の復元元と重なる指定も拒否します。実行前に全組を再照合し、確認後の変更が見つかった場合はどの組にも書き込まずに停止します。実行中にエラーが起きた場合は、その組の処理が終わってから後続の組を停止します。中止やエラー時も完了したファイルは残るため、結果とログを確認してください。

バックアップと復元のパスは別々に保存され、モード切り替えで入れ替わりません。上書きや中止時の扱いは[動作と制限](behavior.md)を参照してください。エラーがある場合は一部だけ復元済みになることがあるため、結果とログを確認します。必要なファイルだけをエクスプローラーでコピーして戻すこともできます。

## 設定・ログ

`%LOCALAPPDATA%\BackupDesk` に `settings.json` と `Logs` を保存します。設定は自動保存され、コピー元一覧・保存先フォルダー名・共通の保存先・同時実行数・復元元と復元先の対応一覧を設定ごとに保持します。

「ログを開く」で直近の処理内容を確認できます。不要な古いログはエクスプローラーから削除できます。「この設定を削除」は設定だけを削除し、バックアップファイルを消しません。

別PCに設定を移すときは、両方のアプリを終了して `settings.json` をコピーし、移行先のフォルダーパスを確認してください。
