## 1.3.1 — .NET 10への移行

2026年11月17日、SDK 10.0.404と.NET Runtime / Windows Desktop Runtime 10.0.15で次を確認しました。

| 対象 | 結果 | 範囲 |
| --- | --- | --- |
| 統合テスト | 47成功・0失敗・2スキップ | バックアップ、復元、複数コピー元、並列数・中止・排他・エラー処理 |
| 設定テスト | 15成功・0失敗 | 旧形式からの移行、保存・復元、コピー元一覧、設定ごとの並列数 |
| WPF内部連携・描画 | 50項目成功・Dispatcher例外0件 | 画面部品・イベントと実処理の連携、設定保持、3フォルダーのコピー・差分更新、画面配置 |
| 単一コピー元の実ファイル負荷検証 | 成功・検証データ削除済み | 空ファイル1万件、および混在ファイル1万件・合計1GiB |
| 配布用の単一EXE | 起動・応答・正常終了を確認 | 自己完結モードと同梱ランタイム10.0.15、展開したWPF部品のSHA-256一致 |

2件のスキップは、実行環境でWindowsのジャンクション作成が許可されていなかったためです。WPF連携は内部での検証であり、デスクトップ上の手動クリック操作ではありません。今回は描画画像の保存を指定していないため、1.3.0の51項目から画像保存の1項目を除く50項目を実行しています。

### 実ファイルの照合内容

混在データは、空ファイル9,000件と実データ1,000件、合計1,073,741,824バイト（1GiB）です。通常のファイル書き込みでデータを作成し、次を確認しました。

- 初回コピー後、全件のSHA-256・サイズ・最終更新日時・フォルダー構成が一致。
- 変更なしで再実行するとコピー0件。
- 更新20件＋追加10件だけを差分コピー。元から削除した10件は保存先に保持。
- 差分反映後も全件を照合し、再実行ではコピー0件。
- コピー元・保存先・検証用の設定や一時ファイルをクリーンアップ。

負荷検証はコピー元1つのバックアップです。複数コピー元の並列バックアップや復元で、同規模の1万件・1GiB負荷試験は行っていません。

### 配布EXEの確認内容

共有.NETの参照先を存在しないパスに指定して起動し、メイン画面の応答と終了コード0を確認しました。ホストの記録で自己完結モードと10.0.15を確認し、展開されたWPFネイティブ部品のSHA-256を同バージョンのランタイムパックと照合しました。検証用データは削除済みです。
